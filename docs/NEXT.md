### 작업 절차 (AGENTS.md 15번)

새 유형은 다음을 모두 갖춰야 한다.
1. 생성기 (`creative.ts` 또는 새 모듈)
2. 생성기를 import 하지 않는 독립 검산 (`verify.ts` 또는 `patternVerify.ts` 방식)
3. 200시드 이상 자동 검사
4. `npm run review` 샘플에서 유형당 5문항 직접 검토
5. `guidance.ts`에 핵심 공식·인식 신호·최단풀이 등록 (`tests/consistency.test.ts`가 누락을 잡는다)
6. `tips.ts` 분류에 배치 (`tests/tips.test.ts`가 누락을 잡는다)

유형을 **추가만** 하면 생성기 버전을 올리지 않아도 된다. 기존 유형의 조건·문장·선지를 바꾸면 올려야 한다.

## 2순위 · 알려진 한계 (고칠 수 있으나 맞바꿈이 있음)

- **`count-6 원형 배치`·`count-14 여사건`의 문항 수가 300시드에서 33~35개.**
  경우의 수 선지 5,000 이하라는 계산 규모 상한(`calibration.ts`) 때문이다. 상한을 올리면 늘릴 수 있으나
  그 상한은 자료 대조로 정한 값이라 함께 재검토해야 한다.
- **선지만 보고 고를 수 있는 문항 0.7%** (`tests/diversity.test.ts`가 2% 미만으로 고정).
  정답이 작거나 부동소수 경계인 경우다. 더 낮추려면 선지 간격을 키워야 하는데 그러면
  '43개 중 125개' 같은 불가능한 선지가 생긴다. 맞바꿈 관계.
- **`ratio-1 증감 후 인원 비율`의 답이 분수(`6/13배`)**. 분모 20 이하로 제한해 두었으나
  기출 05번은 "올해 남학생 수"(정수)를 묻는다. 질문 형태를 바꾸는 편이 실전에 가깝다.

# 자료 대조 결과를 반영한 생성기 1.2.0

2026-10-07. 이 문서는 구현과 검토 상태를 분리한다. 공개 배포 여부는 PR/Actions를 확인한다.

## 구현 범위

링커리어 6회차의 창의수리 120·수열 120문항 조건/해설 규칙과 제공 교재 대조 결과를 바탕으로 아래 **자체 제작 유형 17개**를 추가했다. 원문·숫자 조합·이미지는 복제하지 않았다.

수열 질문은 중간 빈칸, 두 빈칸 합/차/곱/비, 특정 뒤 항을 지원한다. 유형·규칙·난도는 풀이 전에 숨긴다. 정수/소수 분리는 본문에 소수 두 자리를 유지한다. 표와 도형은 숫자를 실제 표/위치에 표시하고 모바일에서 2열로 배치한다.

생성기는 `reference.ts`, 별도 검증기는 `referenceVerify.ts`다. 검증기는 생성기나 질문 조립 함수를 가져오지 않는다. 기존 모든 유형과 함께 런타임 검산·선지 검사·해설 단계 검산을 통과해야 사용할 수 있다.

## 출제 구성

- 전체 코드: 창의수리 89·수열 39 = 128개 세부 유형. 기존 Easy/제외 유형은 과거 기록 재현용으로 보존한다.
- 신규 연습 풀: 창의수리 53·수열 27 = 80개.
- 기본 랜덤 혼합 20문항: 창의수리는 조건부 확률을 최소 1개 포함하고 분야별 과다 반복을 제한한다.
- 기본 수열은 유리수 관련 7문항, 부분 분리·이전 항 곱·군수열·홀짝·계차·교대 연산·표/도형을 포함한 20문항 구성을 사용한다. 표/십자 도형은 회차마다 선택한다.
- Medium 12 / Hard 8. 확인 자료의 조건·규칙 수에 근거한 내부 분류이며 공식 난도 등급이 아니다.
- 명시적 난도/유형 필터, 약점/속도 모드는 해당 조건과 기록 가중치를 우선한다. 모든 유형을 매 세트에 강제로 넣지는 않는다.
- 문제은행 검색·유형별 20문항 집중 훈련·무제한·실전에서 같은 검증 생성기를 사용한다.

## 기록 보존

1.0.0과 1.1.0 생성기를 각각 별도 보존한다. 기존 오답·백업은 원래 버전으로 재현한다. 진행 중/완료한 기존 세션은 유지한다. 시작하지 않았고 답하지 않은 옛 기본 세션만 새 출제 풀로 교체하며 메모는 보존한다. 새 도형 데이터도 백업·즐겨찾기·신고 스냅샷에서 원본과 대조한다.

## 검토 상태와 발견한 수정 사항

Codex가 유형별 5개 시드(179·358·537·716·895)의 85문항을 읽고 조건·표시·계산식을 검토했다. 이것은 외부 사람의 수작업 검수 완료를 뜻하지 않는다. [85문항 검토 자료](reference-review-samples.md)를 제공한다.

- 소수 교대 수열에서 `1.9000000000000001` 같은 메모식과 정수의 `0/1` 대분수 표시를 발견해 소수 한 자리 값으로 정규화했다.
- 소수 두 항의 곱/비에서 지나치게 큰 분모가 발생하면 두 항 차 질문으로 바꾼다. 실제 요구값·메모식·정답 검산도 함께 바뀐다.
- 검사 결과 유형에 집단별 음성률→양성률 복원 단계를 추가하고 해설에서 별도로 검산한다.
- 분수/소수 등비는 첫 항이 정수로만 시작하는 단순 배수 나열을 피한다.
- 도형의 같은 안내 문장만으로 중복 판단하지 않도록 숫자 자료도 원본 문장에 포함한다. 실제 화면은 표/도형으로 표시한다.

AGENTS.md와 QUESTION_POLICY.md의 새 유형 등록 규칙에는 사람이 유형당 5문항을 직접 검토하는 단계가 있다. 외부 사람 검토 또는 사용자의 명시적인 승인 절차 변경 전에는 그 단계가 완료되었다고 표시하지 않는다. PR 검토와 자동 검사 결과를 함께 남긴다.

## 수학·난도 한계

관찰한 대표 규칙 분야는 모두 대응하도록 구현했지만 모든 참고 문항의 세부 조건 조합·도형 모양을 재현한 것은 아니다. 임의 도형의 회전·복잡한 그림 수 세기 등은 지원하지 않는다. 유한 수열의 모든 가능한 규칙에 대한 절대 유일성이나 실제 SKCT 동일 난도를 인증하지 않는다. 실제 학습 시간·첫 시도 정답률을 통해 계산량과 난도를 계속 조정해야 한다.

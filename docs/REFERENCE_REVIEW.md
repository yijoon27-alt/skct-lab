## 현재 지원과 남은 차이

- 신규 출제는 기존의 검증된 창의수리 50개·숫자수열 13개 유형을 사용한다. Easy와 단순 변환 48개는 제외한다.
- 중간 빈칸·두 빈칸 합/차·목표 항을 추가했지만, 에듀윌에서 관찰한 도형/표 기반 수열은 현재 출제하지 않는다.
- 일부 조건부 확률, 세 집단 이상의 색/역할 조합, 구간 변화가 여러 번인 이동 문제 등은 현재 템플릿이 전부 커버하지 않는다.
- 새로운 규칙/유형은 독립 검산·200시드·사람 5문항 검토·PR 절차를 거친다. 기존 유형의 이번 숫자·질문 형식 조정도 자동 검산·브라우저 검사·버전 재현 검사를 수행한다.
- 외부 전문가 또는 사용자의 비교 풀이시간·정답률 측정은 아직 없다. 따라서 “실제 기출과 동일 난도 검증 완료”로 표시하지 않는다.

## 자동 검증 근거

- 전체 111개 생성기 × 200시드: 22,200개 정답·해설 독립 검산.
- 신규 출제 63개 유형 × 500시드: 31,500개 계산 규모 및 정답 검산. 앞 검사와 일부 시드는 겹치므로 53,700개 전부를 서로 다른 문제라고 세지 않는다.
- 구버전 111개 유형 × 5시드: 555개 재현/검증과 구·신 문항 혼합 백업 복원.
- 정답 확인과 해설 각 단계 검산을 분리. 런타임에서 수치 기준이나 정답 검사 실패 문항은 공개하지 않는다.
- 카드 해설 열람은 성적과 분리하고 실전 종료 전에는 해설을 보여주지 않는다.

# 실행·검증 기록

검증일: 2026-10-07 (Asia/Seoul)

## 통과한 검사

- `npm run check`: Vitest 2개 파일 / 133개 테스트 통과, TypeScript 검사 및 Vite 프로덕션 빌드 성공.
- 문항 검증: 111개 세부 유형 × 200개 결정적 시드 = 22,200개 생성 사례.
- 각 세부 유형의 집중 훈련 20문항 세트: 같은 세트 안에서 문제 내용 중복 없음.
- 영역별 20문항, 기본 난도 Easy 5 / Medium 10 / Hard 5, 같은 시드 재현, 최근 문제 회피 검사.
- 정답·해설 오류 및 중복 선지 차단, 계산기 괄호·소수·우선순위·음수·0 나눗셈 차단.
- 실전 이동 제한·답안 잠금·만료 제출·미응답 처리·중복 제출 방지.
- 기록 백업 왕복·잘못된 문항/버전 거절·저장 오류 반환·CSV 안전 이스케이프 및 최신 메모 반영.
- 첫 시도와 재도전 분리. 다른 시드/선지 순서라도 같은 숫자 조건은 재도전으로 집계. 기존 기록의 집계 표시 교정 전 원본 보존.
- 한국 시간 기준 날짜별 학습량 경계 검사.
- `/skct-lab/` base로 빌드하고 실제 HTML 자산 경로 확인 후 로컬 `/` base로 복원.
- 프로덕션 JavaScript에 개발 전용 관리자 문자열/청크가 포함되지 않음 확인.

## 실제 브라우저 검사

macOS의 Chrome을 Playwright로 실행하고 Vite 로컬 서버에서 확인했다. sandbox의 포트/Chrome 실행 제한은 실행 권한 처리를 거쳐 해결했다.

9개 시나리오 모두 통과했다. 전체 실행에서 8개 통과 후, 드롭다운을 찾는 테스트 선택자를 `combobox` 역할로 수정한 집중 훈련 검사 1개를 재실행하여 통과했다. 앞서 백업 검사는 계산기 output도 status 역할을 가진 탓에 선택자 충돌이 있었으며 toast로 한정한 뒤 통과했다.

1. 학습 시작·메모 입력·계산기 소수 연산·오답 판정·새로고침 기록 복원.
2. 실전 해설 비공개·답안 잠금·이전 이동 제한·제출 후 해설 공개.
3. 숫자/Enter/M 단축키·메모 입력 중 선택 차단·정답 자동 다음.
4. 390×844 모바일·다크 모드·계산 오류 표시·가로 넘침 없음.
5. 실전 타이머 만료 상태를 저장한 뒤 새로고침·자동 제출.
6. JSON 다운로드·잘못된 백업 거절·정상 백업 복원·통계 화면.
7. 1440px 데스크톱·신고 ID/시드/버전 저장·문제은행 검색.
8. 분수 수열 유형 선택·집중 훈련 20문항 이동·5개 선지 표시·모바일 메모/계산기 바로가기.
9. 개발 전용 관리자 초안 입력·수식 검사·사람 검토 승인 상태·저장·삭제.

## 미완료/제한

- GitHub 저장소 `yijoon27-alt/skct-lab` 생성·push와 Pages 활성화를 완료했다. GitHub Actions에서 수학 검산·브라우저 검사·빌드가 모두 통과한 커밋만 공개 배포한다. 실행 결과는 저장소 Actions에서 확인한다.
- 실제 교재 원문은 공개하지 않았다. 제공 PDF의 확인 가능한 유형/전략만 참고했다.
- 자동 검산으로 자연어의 모든 모호성이나 실제 시험 난도를 인증할 수 없다. [555개 사람 검토 샘플](review-samples.md)과 [승인 정책](QUESTION_POLICY.md)을 준비했으며 외부 사람의 검수 완료라고 주장하지 않는다.
- 서버 로그인, 기기 동기화, AI API, PDF 자동 적재, 서버 신고 전송은 초기 버전에 포함하지 않았다.

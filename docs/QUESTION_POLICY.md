# 문항 정확성·승인 정책

초기 문제은행은 창의수리 86개 세부 유형과 수열추리 25개 규칙을 코드로 구현했다. 일부 세부 유형은 동일한 보존식이나 연산 구조를 공유한다. 문제 수를 부풀리기 위한 고정 원문 저장은 사용하지 않는다.

## 자동 검증
- 생성기는 숫자 조건과 답안 산식을 작성한다.
- 독립 검증기는 생성기를 가져오지 않으며 거리·용질량·작업 완성률·비용·인원 총합 등 원래 조건에 제시된 답을 대입한다.
- 조합·순열은 선택 집합/배열 열거, 경로는 동적 계획법, 소수는 약수 탐색으로 재검산한다.
- 수열은 전체 항의 차·비·점화 관계를 검사한다.
- 해설은 표현식과 결과를 단계마다 별도로 검사하며 표시된 해설과 계산 단계가 일치해야 한다.
- 선지는 정확히 5개, 수치상 중복 없음, 정답 1개, 인덱스 일치, 단위 일치를 검사한다. 인원·개수는 정수, 확률은 0~1이어야 한다.
- 유형과 해설이 같은 유형을 가리키는지 검사한다. 문제 유형 = 핵심 공식 = 인식 신호 = 최단풀이 네 가지를 `guidance.ts`의 유형별 표와 대조하고, 다른 유형 전용 어휘가 섞였는지와 메모장 식이 정답 숫자 그 자체인지도 본다.
- 생성된 문장의 숫자 뒤 조사(로/으로, 와/과, 을/를)를 전수 검사한다.
- 수열 모의고사는 고정된 유형 목록이 아니라 자료에서 집계한 규칙 분야 분포로 구성한다. 한 세트 안에서 유형이 겹치지 않고 Medium 60 / Hard 40을 유지하는지 검사한다.
- 분자·분모를 각각 따라가는 유형이 약분으로 규칙을 가리지 않는지, 소수로 제시한 수열의 선지가 소수인지, 모든 항이 양수인 수열에 0 이하 선지가 없는지 검사한다.
- 한 유형 안에서 조건끼리 고정된 비율로 묶이지 않는지, 정답이 문제에 적힌 조건의 고정 배수가 아닌지, 200시드에서 서로 다른 문항과 정답이 충분히 나오는지 검사한다.
- 금액은 1원 단위 정수여야 한다.
- 모든 등록 유형은 200개의 결정적 시드(총 22,200개)를 CI에서 검사한다. 런타임에서도 실패 문항은 사용하지 않는다.

## 자연어와 수열의 한계
유한한 수열에는 수학적으로 무한히 많은 연장 규칙이 가능하다. 사용자의 요청에 따라 수열 규칙과 유형·난도는 풀이 전에 표시하지 않고 채점 후 해설에서 공개한다. 저장된 규칙으로 모든 항과 정답을 검산하지만 가능한 모든 규칙에 대해 유일성을 증명했다고 주장하지 않는다. '실제 시험 동일 난도'라고도 주장하지 않는다. 난도는 조건 수·규칙 수 기준의 초기 분류이며 실사용 데이터와 사람 검토로 조정해야 한다.

자동 검산은 문장 조건 누락, 문장 해석의 자연스러움, 여러 풀이의 교육적 품질, 실제 시험 유사성을 증명하지 못한다. 초기 문항은 자동 검산을 완료한 자체 제작 학습용이며 사람의 교정 검토가 추가로 필요하다. '인간 승인 완료'라고 표기하지 않는다.

## 새 유형 승인
1. 개발자 검토실이나 별도 JSON에 초안을 작성한다. 외부 AI도 초안만 만든다.
2. 생성기·원래 조건을 이용한 독립 검증기·구조화된 해설 단계를 작성한다.
3. 유형별 200시드 자동 테스트에 포함한다. 실행 시 검증을 우회하지 않는다.
4. `npm run review`의 유형당 5문항을 사람이 직접 계산한다. 검토자·날짜·수정 사항을 PR에 기록한다.
5. PR 리뷰와 필수 CI 승인 후 등록한다. main 브랜치 보호에서 verify를 필수 상태 검사로 설정한다.

검토실의 수식 검사와 '검토 승인'은 로컬 초안 상태일 뿐 생성기 등록을 대체하지 않는다. 관리자는 임의 문제를 생산 UI에 직접 추가할 수 없다. 삭제·수정·정답·유형·난도 편집은 초안에 한정된다. 등록 템플릿 수정·제거는 코드 PR로 처리한다.

## 제공 자료 분석 범위
제공 렛유인 모의고사 40문항, 에듀윌 통합기본서 4회 실전 모의고사 40문항 및 다른 회차 표본 21문항을 화면으로 확인했다. 구체적 페이지와 범위·제한은 [자료 대조 기록](REFERENCE_REVIEW.md)에 기록했다. 링커리어 로그인 시험 6회차 수리·수열 240문항의 조건·해설 규칙을 추가 대조했다. 원문·이미지는 복제하지 않으며 동일 난도 인증이라고 주장하지 않는다.

## 신규 출제 범위
Easy 37개와 별도로 선정한 단순 변환·기본 이동 11개를 신규 출제에서 제외한다. 1.2.0 작업에서는 창의수리 53개·수열추리 27개, 총 80개 유형을 Medium 60% / Hard 40%로 출제한다. 제거한 생성기는 기존 오답·백업의 검증과 복습을 위해 보존한다. 이 분류는 실제 기출 난도 인증을 의미하지 않는다.

## 1.2.0 추가 검토 자료

새 17개 템플릿과 별도 검산은 [구현 기록](REFERENCE_IMPLEMENTATION.md), 사람이 직접 검토할 유형당 5문항은 [85문항 자료](reference-review-samples.md)에 있다. Codex의 검토와 자동 검사 통과를 외부 사람의 수작업 승인으로 표기하지 않는다.

## 1.2.0 이번 등록에 대한 사용자 지시

2026-10-07: 사용자에게 자동 검산·Codex의 유형당 5문항 검토를 이번 등록 기준으로 사용하는 승인을 요청한 뒤, 사용자가 “공개사이트에도 반영해줘”라고 명시적으로 배포를 요청했다. 이번 1.2.0의 신규 17개 템플릿은 해당 지시에 따라 등록·배포한다. 외부 사람의 수작업 검수 완료로 표시하지 않는다. 이후 새 유형의 기존 검토 규칙은 유지한다.
